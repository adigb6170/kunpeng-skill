# 可再生成规范

## 定位

“反向提示词”不是单独产物。蒸馏最终必须形成模型无关、参数明确、可检查的再生成规范；需要交给 Seedance、图像模型或写作模型时，再把规范适配成该工具的输入格式。

不承诺逐帧、逐像素或逐字完全一致。忠实度取决于参考素材权限、生成模型能力、随机性、可用控制条件和复核迭代。

## 先声明目标

- **忠实重建**：内容、结构和风格都尽量接近；仅处理用户拥有或获授权的素材。
- **同风格新内容**：迁移表现机制，替换主题、主体、事实、案例和专有表达。

未说明时默认“同风格新内容”。不要把两种目标混在一个规范里。

## 通用结构

```text
目标效果：生成物要让受众感受到什么、完成什么任务
输出约束：媒介、尺寸/时长/篇幅、语言、平台和技术限制
不可变项：必须保留的结构、关系、参数和识别特征
内容变量：本次可替换的主题、主体、场景、文案和数据
生成顺序：从结构到局部按什么步骤建立
阶段规则：每一段、镜头、区域或章节的职责和参数
连续性：跨镜头、跨画面或跨段落必须保持什么一致
声音/文字：对白、旁白、音乐、字幕、字体或语言规则
负向约束：明确不要出现的内容、效果和常见失败
验收表：可观察、可比较、可判定的通过条件
```

## 参数要求

- 优先写绝对值、范围、比例、顺序、数量和触发条件。
- 无法精确测量时写相对关系，例如“标题约为正文 2 倍”“转折后镜头长度缩短约三成”。
- 形容词必须落到可见或可听参数；“电影感”要展开为画幅、景别、机位、光线、景深、调色、运动和声音。
- 每条规则标明全局、阶段、局部或例外，避免互相冲突。
- 同时写 Do/Don't，防止生成模型用表面效果替代核心结构。

## 媒介必填项

### 视频

总时长和画幅、段落比例、逐镜表、景别/机位/运动、主体动作、转场、色彩与光线、文字图形、对白/旁白、音乐/音效、节拍点、连续性和结尾状态。

### 图片

画布比例、主体数量和区域坐标、姿态/视角/裁切、空间层次、镜头感、光源、色彩及占比、材质、背景、文字层级、后期处理和禁止元素。

### 文章

读者和目的、篇幅、段落职责与比例、叙述视角、语气、句长节奏、词汇倾向、修辞动作、格式、事实边界、内容变量和禁止复用的表达。

## 模型适配

适配具体生成工具时只做格式转换，不改变规范本身：

1. 保留不可变项、阶段结构、内容变量和负向约束。
2. 把工具支持的参考图、首尾帧、时间轴、镜头控制或结构化字段映射进去。
3. 工具不支持的控制项改成验收条件，不假装已被模型约束。
4. 记录模型版本、随机种子、参考权重和生成参数，方便复现；未知参数不编造。
5. 生成后必须重新分析候选结果，不能仅凭提示词看起来完整就判定通过。

## 复核

确定性诊断可运行：

```bash
python scripts/kunpeng.py compare <参考文件> <候选文件> --mode faithful
python scripts/kunpeng.py compare <参考文件> <候选文件> --mode style
```

诊断分数只覆盖尺寸、色彩、结构代理值、节奏或文字统计，不能证明语义和审美等价。最终按三层复核：

1. **硬约束**：格式、尺寸、时长、篇幅、段数/镜头数、文字和必备对象。
2. **结构相似**：构图、时间轴、段落职责、节奏、色彩角色、声音关系和风格规则。
3. **语义与质量**：主体/事实正确、连续性、自然度、可读性、伪影、错误文字和版权边界。

忠实重建任一硬约束失败就退回；同风格任务不得因为内容不同而扣“忠实内容”分，也不得因为色调接近就忽略结构和表达机制。
