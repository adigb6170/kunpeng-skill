# 图片与视觉素材蒸馏

## 直接执行

纯图片、海报、界面截图、品牌资产或批量视觉素材蒸馏不提产品问题。先运行：

```bash
python scripts/kunpeng.py probe --profile image
python scripts/kunpeng.py images <图片或目录> --output <过程目录>
```

读取 `manifest.json`、`contact-sheet.jpg` 和每项 `analysis.json`；需要判断主体、材质和设计意图时必须查看原图，不能只看统计值。

已部署的 OpenCV、Pillow 和 PaddleOCR 必须优先运行。OCR 缺失或失败时只把文字阶段降级为宿主视觉复核，尺寸、色彩和构图指标继续处理；宿主没有实际查看原图前不能声称文字缺口已覆盖。

## 自动提取内容

- 尺寸、比例、方向、格式、透明通道和动画帧数。
- 主色及占比、亮度、明暗范围、对比度、饱和度和冷暖倾向。
- 边缘密度、清晰度代理值、视觉重心、对称性和浅色留白代理值。
- PaddleOCR 识别文字、位置、置信度和估算文字覆盖率。
- 批量联系表，用于观察系列一致性、变化范围和异常样本。

这些数值是证据，不是审美结论。它们不能自行识别人、商品、镜头意图、字体名称、真实光源或隐藏交互。

## 人工/智能体分析

1. **内容层**：主体、动作、场景、叙事、信息目标和使用环境。
2. **构图层**：画布比例、视角、焦点、网格、区域占比、层级、留白、裁切和视觉动线。
3. **成像层**：镜头感、透视、景深、曝光、主辅光、阴影、反射、颗粒和后期处理。
4. **设计层**：字体类别、字重层级、字号比例、对齐、形状、圆角、描边、图标和装饰母题。
5. **品牌层**：稳定人格、情绪、识别方式、跨载体规则和不可迁移的专有资产。
6. **批量层**：每张先独立记录，再计算稳定规律、可变参数、例外和错误样本。

## 两种目标

### 忠实重建

仅用于用户拥有或获授权的素材。固定画布、主体身份与数量、位置、姿态、视角、裁切、文字、颜色、光线、材质和背景关系；把每项写成可检查参数，不使用“高级感”等模糊词代替。

### 同风格新内容

固定构图逻辑、色彩角色、光线规则、材质、图像处理、字体层级和情绪；把主体、文案、场景和局部颜色声明为变量。不要复制 Logo、角色、独特插画、商标或整套受保护视觉身份。

## 最终产物

- 视觉定位和稳定原则。
- 画布、网格、区域占比、视觉焦点和空间关系。
- 主体、背景、镜头、光线、色彩、材质、文字和后期参数。
- 可变项与不可变项。
- Do/Don't、常见失败和媒介适配。
- 按 `reproduction-standard.md` 写可再生成规范与验收表。

图片少于三张时不要声称形成完整风格系统；单张只能得到该画面的重建规范和候选风格规律。
