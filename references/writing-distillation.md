# 文章与表达蒸馏

## 直接执行

纯文章、书籍、课程文字、字幕或文档蒸馏不提产品问题。先本地提取：

```bash
python scripts/kunpeng.py probe --profile document
python scripts/kunpeng.py documents <文档或目录> --output <过程目录>
```

支持 PDF、DOCX、PPTX、HTML、Markdown、TXT、结构化文本和常见字幕。扫描 PDF 在本地用 PaddleOCR；无法解析的旧格式先离线转换为支持格式。

扫描 PDF 的文本不足时先渲染低文本页。PaddleOCR 不可用时只降级这些页面，保留渲染图供宿主实际查看；其他可提取页面继续进入全文和分块，未查看的页面保持未覆盖。

## 上下文读取

1. 先读 `manifest.json` 和每项 `analysis.json`，掌握结构、样本与统计。
2. 先从开头、中段、结尾样本建立全局判断。
3. 沿 `chunk-index.json` 只读取当前论证或风格问题需要的块。
4. 长文每轮保留同一份全局概览，避免分块后断章取义。
5. 批量文章逐项建事实卡后再聚类，不把作者或栏目差异抹平。

## 蒸馏维度

- **内容结构**：开头如何立题，信息按什么顺序展开，论点、证据、案例、反例和结尾如何连接。
- **叙述视角**：第一/第二/第三人称，作者与读者距离，是否直接下判断。
- **语气**：克制或强烈、正式或口语、确定或试探、理性或情绪化，并用具体句式证明。
- **句法**：句长分布、长短句交替、并列/递进/转折、主动被动、提问和感叹频率。
- **词汇**：抽象与具体、术语密度、动词强度、形容词密度、口头语、比喻和重复词。
- **节奏**：段落长度、留白、小标题、列表、对话、金句和信息密度的变化。
- **表达动作**：定义、比较、设问、举例、反驳、故事、数据、号召和收束如何触发。
- **边界**：哪些特征属于主题、媒介或篇幅，不应误判为稳定文风。

脚本统计只提供可测证据。论证逻辑、幽默方式、情感变化和修辞目的必须结合原文判断。

## 两种目标

### 忠实整理

保持事实、观点、顺序、专有名词和必要措辞，改善结构或格式时不得改变含义。长篇引用和受保护原文只在授权范围内处理。

### 同表达新内容

保留结构比例、叙述距离、句法节奏、词汇倾向、修辞动作和格式规则；主题、事实、案例和表述必须重新生成。不要复制标志性长句、段落、独特故事或连续原文。

## 最终产物

- 文体定位、读者关系和目标效果。
- 篇章结构及各段职责和比例。
- 语气、视角、句法、词汇、节奏和修辞规则。
- 内容变量、事实核验规则、禁止表达和反例。
- 一份可直接用于新主题的写作流程与逐段验收表。
- 按 `reproduction-standard.md` 形成模型无关的可再生成规范。

最终标准应让另一个写作系统在换主题后仍呈现相近的组织和表达机制，同时能明显看出内容是新的。
